# Simulations Showcase Website
Simulations are showcased [here](https://volatilesounds.github.io/simulations/).

This HTML file demonstrates a dynamic grid of simulations hosted in the repository. Each simulation is a separate React/Vite project built and deployed under `simulations/<sim-name>/` on GitHub Pages.

## How It Works

### 1. Grid Setup
The page uses a CSS grid to layout simulation "cells":
- `.grid` is the container for all simulations.
- `.sim-cell` represents each simulation slot.
- `.sim-title` shows the name of the simulation.
- `.sim-mount` is the div where the React app will be mounted. It takes full width/height of the cell and starts invisible, fading in once the simulation is ready.

### 2. Simulation List
The array simulations contains the folder names of the simulations to display:
Each name must match the folder deployed under `simulations/` in your GitHub Pages.
```js
  const simulations = ["sim-temp", ...];
```

### 3. PascalCase Conversion
Each simulation project exports a mount function in the global window object. The function name is generated from the simulation folder name using PascalCase:
- `sim-temp` → `SimTemp` → mount function: `mountSimTempApp`
- `sim-particles-test` → `SimParticlesTest` → mount function: `mountSimParticlesTestApp`

The helper function:
```js
function normalizePascalCaseName(name) {
  return name
    .replace(/[^a-zA-Z0-9]/g, " ")
    .split(" ")
    .filter(Boolean)
    .map(w => w[0].toUpperCase() + w.slice(1))
    .join("");
}
```

### 4. Dynamic Mount Container Creation

For each simulation:
- A `div.sim-cell` is created as a grid cell.
- Inside it, a `div.sim-title` shows the name.
- A `div.sim-mount` is created to serve as the mount point for the React app. It is uniquely identified as `vsounds-render-<sim-name>-<index>`.

### 5. Loading Manifest

Each simulation build outputs a `manifest.json` (generated by Vite) containing the hashed file names for JS and CSS.
This allows the loader to dynamically fetch the correct JS/CSS files without hardcoding hash names.
The manifest is fetched using:
```js
fetch(`${basePath}/${simName}/manifest.json`)
```

### 6. Dynamically Loading Assets

Once the manifest is loaded:
- The CSS and JS files are loaded.
- When the JS loads, the global mount function is called.
This mounts the React app into its dedicated `div.sim-mount`.

### 7. Key Advantages
- Multiple simulations on one page: Each simulation is isolated and mounted independently.
- No hardcoded file hashes: The manifest ensures that JS and CSS files are loaded dynamically.
- Reusable container structure: Mount points are generated programmatically with unique IDs.
- Scalable: To add new simulations, just include the folder name in the simulations array.

This setup ensures that each React/Vite simulation is loaded dynamically and independently, making it easy to maintain multiple interactive simulations on the same page.
